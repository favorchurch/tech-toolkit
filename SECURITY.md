# Security policy

This is a **public** reusable training/documentation repository. It intentionally does not include production credentials, private network topology or ministry member data.

If you discover a vulnerability or accidentally exposed confidential information, please **do not post the details in a public issue**. Use the existing approved private Favor Tech security-reporting channel or GitHub's private vulnerability reporting when enabled. Notify the appropriate system owner so containment and any key rotation can begin safely.

For publication rules, data classification, local runbook restrictions, access review and the incident response boundary, see the [security standard](docs/SECURITY.md).

The repository's lightweight document checker does **not** validate full Git history, hidden images, or all possible secret formats. Human security review and separate historical scanning remain required.
